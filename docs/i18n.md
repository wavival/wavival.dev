# Languages: Spanish and English

> Last updated: 2026-10-03

Spanish is the default locale and lives at the root. English is a full mirror under `/en/`. Every public page exists in both languages.

## Page map

| Spanish              | English                | Notes             |
| -------------------- | ---------------------- | ----------------- |
| `/`                  | `/en/`                 | Home              |
| `/proyectos/`        | `/en/projects/`        | Filterable index  |
| `/proyectos/<slug>/` | `/en/projects/<slug>/` | Nine case studies |
| `/servicios/`        | `/en/services/`        |                   |
| `/cotizar/`          | `/en/quote/`           | Quote form        |
| `/sobre-mi/`         | `/en/about/`           |                   |
| `/contacto/`         | `/en/contact/`         |                   |
| `/herramientas/`     | `/en/uses/`            |                   |
| `/privacidad/`       | `/en/privacy/`         |                   |
| `/404`               | `/en/404`              | `noindex`         |

The map is `EN_PAGE_MAP` in `src/i18n/utils.ts`. The sitemap, the language toggle and the hreflang alternates all read it, so a page is added there first.

## How a page knows its language

- `getLangFromUrl()` returns `en` when the first path segment is `en`, otherwise `es`. `Layout.astro` sets `<html lang>` from it and derives `og:locale`.
- `siteRoutes(lang, base)` returns the localized internal routes; components never hard-code a path.
- `getAltLangUrl()` gives the language toggle its target: the paired page, or the home of the other language for the 404 pages and unknown paths.
- `ariaCurrent()` marks the current page in the navigation and the footer.

## Where the copy lives

- Shared UI text (navigation, footer, common labels): `src/i18n/ui.ts`, 38 keys that exist in both languages. `useTranslations(lang)` falls back to Spanish.
- Page copy: each Spanish page has an English mirror file under `src/pages/en/`, written separately.
- Project content: `src/data/projects.ts` holds Spanish at the top level and an `en` object per case study with the translated text fields (summary, problem, solution, architecture, results, learnings, links and image alt). Stack lists use `toolsEn` and `descriptionEn` in `src/data/stack.ts`.
- Quote form labels are passed from each quote page.
- CV files are per language: `cv_valentina_ramirez_es.pdf` and `cv_valentina_ramirez_en.pdf` (`cvHref()`).

## What stays in Spanish on purpose

- The notification email that `api/quote.ts` sends to the owner (labels and subject).
- Internal documents: `docs/brand.md` and `docs/commercial.md`.

## Rules

- A change to copy in one language needs the same change in the other in the same pull request.
- Spanish slugs are the canonical ones; English slugs mirror them through `EN_PAGE_MAP` and `/en/projects/<slug>`.
- Every indexable page passes `alternates` with `es`, `en` and `x-default` (Spanish) to `Layout`; the 404 pages do not.
- The language is chosen with the toggle in the header; nothing redirects by browser language.

## Tests

`tests/i18n-utils.spec.ts` (helpers and the map), `tests/i18n.spec.ts` (`lang`, canonical, CV and reciprocal hreflang), `tests/routes.spec.ts` (every route answers 200 with one `h1`), `tests/case-studies.spec.ts` (English fields and lengths per case study).
